# masscan-checker

Программа на Go для автоматического сетевого сканирования на базе Masscan.
Периодически сканирует заданный адрес/диапазон, определяет открытые порты, пытается получить
баннер сервиса, сравнивает результат с предыдущим сканом и уведомляет владельца в Telegram
о новых открытых портах.

## Возможности

- Запуск Masscan из Go-кода (многопоточное сканирование средствами самого masscan)
- Определение сервиса на порту через banner grabbing (TCP-подключение)
- Хранение истории сканов на уровне файлов (result.json / previousRes.json)
- Сравнение текущего скана с предыдущим обнаружение новых открытых портов
- Уведомления в Telegram при обнаружении нового порта
- Конфигурация через отдельный config.json, без правок в код
- Периодическое сканирование (бесконечный цикл с паузой между итерациями)

## Требования

- **macOS** (протестировано) или Linux с установленным Go 1.20+
- Установленный Masscan (`brew install masscan` на macOS, `apt install masscan` на Debian/Ubuntu)
- Аккаунт Telegram (для создания бота)

> Windows не тестировался. Masscan на Windows требует Npcap и сборки из исходников;
> текущий код также жестко вызывает `sudo`, что не работает в Windows — для запуска
> на Windows потребуется адаптация кода и запуск от имени администратора.

## Настройка Telegram-уведомлений

1. В Telegram найдите **@BotFather**, отправьте команду `/newbot` и следуйте инструкциям —
   в ответ вы получите токен бота (строка вида `123456789:ABC...`)
2. Найдите своего бота по username и напишите ему любое сообщение (бот не может писать первым)
3. Откройте в браузере (подставив свой токен):

https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates

4. В ответе найдите `"chat":{"id": ЧИСЛО, ...}` — это ваш `chat_id`
5. Впишите оба значения в `config.json`:
```json
   "tg_token": "ваш_токен",
   "tg_chat_id": "ваш_chat_id"
```

## Формат config.json

```json
{
  "target": "45.33.32.156",
  "ports": "22,80,443",
  "rate": "1000",
  "tg_token": "YOUR_TELEGRAM_BOT_TOKEN",
  "tg_chat_id": "YOUR_TELEGRAM_CHAT_ID"
}
```

- `target` — IP-адрес или диапазон для сканирования
- `ports` — список портов через запятую
- `rate` — скорость сканирования (пакетов в секунду), параметр masscan `--rate`
- `tg_token` — токен Telegram-бота
- `tg_chat_id` — ID чата, куда отправлять уведомления

## Запуск

Masscan требует привилегий root (использует raw sockets), поэтому запускайте программу через sudo:

go build -o scanner
sudo ./scanner


Программа будет сканировать заданный адрес в бесконечном цикле с паузой между итерациями,
сравнивать результат с предыдущим сканом и присылать уведомление в Telegram при обнаружении
нового открытого порта.

## Структура проекта

- `main.go` — точка входа, оркестрация всего пайплайна
- `models.go` — структуры данных (Port, Host, Config)
- `scanner.go` — запуск Masscan
- `storage.go` — работа с файлами результатов (ротация, чтение)
- `differ.go` — сравнение текущего и предыдущего сканов
- `banner.go` — banner grabbing (определение сервиса на порту)
- `notifier.go` — отправка уведомлений в Telegram
